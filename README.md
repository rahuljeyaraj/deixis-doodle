# Point and Draw

Robots understand *what* now. They still don't understand *where*.

Point and Draw lets you tell a robot where by doing what people do with each other: point and say "here", "that one", "this big". A converted Ender 3 pen plotter draws what you asked, where you pointed, at the size you showed, and shows you its guess with a pen-up hover before it commits.

Entry for the Nebius x NVIDIA Global AI Hackathon, Physical AI track. **Work in progress.**
